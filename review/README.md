# Исходный пакет для ревью Firefox

Keyloom использует обычные JavaScript IIFE без минификации и транспиляции.
Для получения устанавливаемого пакета нужен Node.js 22.13+:

```sh
node scripts/build.mjs firefox
```

Результат: `artifacts/firefox/`. Упакуйте содержимое этого каталога в ZIP,
manifest.json должен находиться в корне архива. npm install не требуется.
Сборка копирует extension/ и заменяет background на Firefox event page,
добавляя идентификатор, минимальные версии и декларации данных.

В `review/lz-string-1.5.0.js` находится оригинальный читаемый исходник библиотеки
из npm-пакета lz-string@1.5.0. `review/lz-string.LICENSE` — лицензия из того же пакета.
Комментарии исходника оставлены без изменения. Устанавливаемый
`extension/vendor/lz-string.js` побайтово совпадает с `libs/lz-string.min.js`
в опубликованном npm-пакете:

https://registry.npmjs.org/lz-string/-/lz-string-1.5.0.tgz

SHA-256 минифицированного файла:
`95f4d1cbf099f57161b664bc048426ec3df92637801a4c79116e83315aa787e7`.

Сборка не генерирует эту стороннюю библиотеку: оригинальный файл уже включён.
Лицензия собственного кода в LICENSE. Сервер и секреты не входят в расширение.
