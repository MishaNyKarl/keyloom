# Keyloom 0.8.0

- Ежедневные планы по времени, целям и языкам, прицельные блоки и отработка ошибок.
- Переход к следующему заданию прямо на Monkeytype в той же вкладке.
- Одинаковый текст разминки и завершения для сравнения времени и точности.
- Персональный словарь, повторения целей и наблюдение переноса навыка.
- Графики с адаптивной шкалой и подсказками по тестам.
- JetBrains Mono и три темы с карточками палитр.

История и существующие планы сохраняются. Новые шаги разминки появляются в новых планах.
Шрифты поставляются локально под SIL OFL; разрешённые web-accessible ресурсы — только
fonts/*.woff2 для monkeytype.com. Область сбора клавиатурных событий не расширяется.

Проверки: node --test, node scripts/check.mjs, сборка Firefox и Mozilla web-ext lint.
Полное ручное прохождение на установленном подписанном Firefox ещё не проверено.
