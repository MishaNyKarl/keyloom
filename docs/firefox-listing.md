# Карточка Firefox Add-ons

Название: **Keyloom — персональные тренировки печати**

Краткое описание:

Персональные тренировки по ошибкам Monkeytype: пары, связки и слова, статистика RU/EN.

Полное описание:

Keyloom помогает понять, что мешает печатать точнее и быстрее. Пройдите тест
на Monkeytype, посмотрите сложные буквы, пары, связки и слова, затем запустите
упражнение по своим слабым местам прямо в Monkeytype.

- Русский и английский; time, words, custom и quote.
- Ошибки первого ввода, включая исправленные опечатки, и интервалы между буквами.
- Ручной выбор целей, длительности и количества слов; подсветка целей в тексте.
- Практика пар, связок из 3–5 букв, заглавных, цифр и пунктуации.
- Графики прогресса, календарь активности и история по языкам и раскладкам.
- Локальный экспорт/импорт JSON и добровольная синхронизация с собственным HTTPS-сервером.

По умолчанию история хранится в браузере. Ввод собирается только из поля теста
Monkeytype. Нет рекламы и автоматической телеметрии. При запуске упражнения его
слова передаются Monkeytype. Синхронизация требует отдельного подключения;
общедоступного облачного аккаунта нет. Панель анализирует последние 160 сессий / 6 МБ.

Версия alpha: интерфейс на русском, Firefox desktop 142+. Неофициальное дополнение,
не связано с разработчиками Monkeytype. Изменения сайта могут влиять на сбор данных.

## Notes for Reviewers

Расширение не требует аккаунта для локальных функций. Откройте monkeytype.com,
выберите English/Russian и обычный тест, завершите его и откройте панель через popup.
Сравните историю, запустите custom-тренировку и вернитесь к её результату.
Деморежим открывается ссылкой в настройках: он содержит только синтетические данные.

Синхронизация — добровольная функция для собственного сервера. Тестовый сервер
можно запустить по `docs/server.md`; используйте отдельную SQLite-базу и новый токен.
Личный production-доступ владельца не входит в пакет и не предоставляется для ревью.

Permissions: storage — локальные агрегаты и настройки; alarms — повтор синхронизации;
content script — только monkeytype.com; optional HTTPS host permission — только
выбранный сервер после действия пользователя. В Firefox запрашиваются optional
websiteActivity/authenticationInfo при включении синхронизации; websiteContent
объявлен для custom-текста, передаваемого Monkeytype.

Исходные IIFE-скрипты не собираются и не транспилируются. Единственный минифицированный
компонент — lz-string 1.5.0 (MIT). Происхождение:
https://www.npmjs.com/package/lz-string/v/1.5.0
Читаемый исходник: https://github.com/pieroxy/lz-string/blob/1.5.0/libs/lz-string.js
Команда сборки Firefox: `node scripts/build.mjs firefox` (Node.js 22.13+).
В корне ZIP расширения должен быть manifest.json; сервер, тесты и документы туда не входят.
