# Личное серверное хранилище с локальным кешем

Владелец запросил хранение на собственном VPS без домена и деплой через GitHub.
Сервер уже обслуживает другие приложения, поэтому Keyloom использует отдельные
unit, пользователей, loopback-порт и TLS-порт 8443.

Выбран Node.js 24 и встроенный SQLite: нет npm-зависимостей, общий валидатор с
расширением, транзакции и идемпотентность по ID. Альтернатива с PostgreSQL и аккаунтами
сложнее требуемого личного хранилища. JSON-файл проще, но хуже подходит для растущего
архива и конкурентной записи. Версия локальной схемы остаётся 1, история не очищается.

Локальный кеш сохраняет офлайн-работу. Передача начинается только после явного
подключения; HTTPS обязателен, редиректы запрещены. Личный токен — единственная
идентичность текущей версии. Для публичного облака потребуются отдельные пользователи,
изоляция, восстановление доступа и удаление аккаунта; общий токен распространять нельзя.

Сервер сохраняет все сессии; панель пока ограничена существующим окном 160/6 МБ.
Неизменяемые результаты с повторным ID игнорируются. Планы и настройки не синхронизируются.
Копии базы на том же сервере облегчают восстановление после ошибки, но не заменяют
внешний backup. Деплой не меняет базу; откат кода возможен без отката данных.
